How to choose the right service.

Start with the source. If water is coming from a pipe, begin with the plumbing group. If it came from outside, use the weather group. If you only know that a floor, wall or ceiling is wet, start there. Dispatch can sort it out on the phone in a minute.

Many jobs involve more than one service. A burst pipe may need extraction, drying and drywall work, and each has its own page. Services are the same whether the loss is a single room or a whole floor, and the crew explains the scope before work starts.
